# Security

## Reporting a vulnerability

Email **hello@dubaiwealthindex.com** with "Security" in the subject. Please do
not open a public issue for a security report: an issue is visible to everyone
the moment you file it, before we can act on it.

Include what you can: what you did, what happened, and what you expected. A
proof of concept helps but is not required.

**We will acknowledge within 3 business days** and tell you whether we can
reproduce it. If we can, we will keep you updated until it is fixed and credit
you in the release notes unless you would rather we did not.

## Scope

This repo publishes the plugin for Dubai Wealth Index: manifests, an MCP server
address, and Markdown skills. The service itself runs at
https://dubaiwealthindex.com.

In scope here: anything in this repo that would lead a user into an unsafe
setup, such as a server address that is not ours.

Also in scope, and more valuable: the hosted MCP server and its OAuth sign-in at
`https://dubaiwealthindex.com/api/mcp`. Report those to the same address.
